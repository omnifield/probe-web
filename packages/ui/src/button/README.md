<h2 id="анатомия">🧩 Анатомия</h2>

```
root
```

| часть      | значение                                                         | принимает внутри | рисуется |
| ---------- | ------------------------------------------------------------------ | ------------------ | ---------- |
| 🔘 `root`  | кнопка целиком — один узел, по умолчанию настоящий `<button type="button">` | текст, иконку       | `Button`  |

Один узел — единственный компонент кита без составного дерева. Дотированный адрес
(`button.<часть>`) у него невозможен в принципе — нечего адресовать, кроме самого узла.

<h2 id="состояния">🎛️ Состояния</h2>

|      | состояние     | метка                | значение                                                                             |
| ---- | ------------- | ---------------------- | ---------------------------------------------------------------------------------------- |
| 🖱️   | hover         | `:hover`               | указатель наведён на кнопку                                                              |
| ⌨️   | focus-visible | `:focus-visible`       | фокус пришёл с клавиатуры                                                                |
| 👆   | active        | `:active`               | кнопка нажата и удерживается                                                             |
| 🚫   | disabled      | `[data-disabled]`       | нельзя нажать — обработчик не вызывается                                                 |
| ⏳   | busy          | `[aria-busy="true"]`    | идёт работа — атрибут ставит потребитель вместе с `disabled`, свой `loading`-проп кит не несёт |
| 📖   | expanded      | `[data-expanded]`       | кнопка раскрыла то, чем управляет — атрибут приходит от внешнего компонента              |
| 👇   | pressed       | `[data-pressed]`        | кнопка-переключатель нажата — сама нажатость принадлежит внешнему компоненту, вид — кнопке |

> [!NOTE]
> `expanded`/`pressed` кнопка никогда не ставит сама — это состояния внешнего компонента
> (поповер-триггера, переключателя), в который кнопка встроена через `as`; кнопка лишь несёт
> свой адрес, а состояние подкладывает владелец поведения.

```tsx
const onDispatch = (event: DispatchedEvent) => {
  // Клик по кнопке, возвращает payload как есть — кнопка его не решает и не трогает.
  // event.context.payload = { id: "row-1" }
};

<RenderTree tree={tree} registry={registry} data={data} dispatch={onDispatch} />;
```

> [!NOTE]
> Кнопка — единственный компонент кита с `passport.selfAssembly`: голая ссылка `{ node: "button" }`
> в чужой сборке разворачивает клик → `select` и подпись из данных сама, без своих `on`/`children`
> на узле ссылки.

<h2 id="рецепт">🎨 Рецепт</h2>

Доказательный рецепт (`playground/recipe.ts`) — доказывает, что паспорт МОЖНО одеть целиком
настоящей скин-механикой (`skinGaps` пуст, CSS реально генерируется). В продакшене не участвует.

Три именованных вида (`primary`/`quiet`/`danger`) плюс общая база — единственный компонент кита,
чей proof-рецепт несёт реальную ось `data-variant` с несколькими значениями, а не один плоский вид:
меньше трёх не хватило бы, чтобы показать пересечение «несколько видов сразу» (`compoundVariants`
на `primary`+`danger` вместе), а не просто «для одного».

<h2 id="использование">🚀 Использование</h2>

**Ручная сборка** — компонент собирается вручную, JSX-композицией, без схемы и движка.

```tsx
<Button onClick={save}>Save</Button>
```

**Как ссылка на чужую сборку** — через `selfAssembly` клик и подпись разворачиваются сами, без
собственных `on`/`children` на узле ссылки.

```tsx
const tree: AssemblyTree = {
  components: {
    root: "ref",
    nodes: {
      ref: { id: "ref", type: "button", parentId: "owner", children: [], bind: { label: "/title", payload: "/payload" } },
    },
  },
};

<RenderTree tree={tree} registry={registry} data={{ title: "Открыть", payload: { id: "s1" } }} />;
```

**Вид через `data-variant`, не проп.** У кнопки нет прописанного имени вида по умолчанию —
непереданный вид не ставит атрибут вовсе.

```tsx
<Button data-variant="primary">Save</Button>
```

**Встроена во внешний компонент** — `as` берёт `Button`, кнопка остаётся тем, чем визуально
является, а поведение и состояние (`expanded`/`pressed`) приносит внешний компонент.

```tsx
<ToggleGroup>
  <Button as={ToggleGroupItem} value="bold">B</Button>
</ToggleGroup>
```
