# Карта покрытия — заказ C (theming-and-modes)

**Сбор от 2026-08-15.** По каждому из 8 вопросов: чем закрыт и что осталось. Особенность захода: почти всё — нормы W3C/WHATWG с нумерованными разделами, поэтому цитаты идут с точными адресами внутри документа. Статус каждой нормы выписан ТЕМ, ЧЕМ ЕГО ОБЪЯВИЛ ИЗДАТЕЛЬ, отдельно от таблиц поддержки браузеров (требование заказа).

## Статусы норм — снимок на 2026-08-15 (выписано по издателю, не по браузерам)

| норма | статус по издателю | редакция |
|---|---|---|
| CSS Color Adjust L1 | Candidate Recommendation Snapshot | 16.12.2025 |
| Media Queries L5 | Working Draft | 19.02.2026 |
| CSS Color L5 | Working Draft | 31.07.2026 |
| CSS Color L4 | Candidate Recommendation Draft | 06.08.2026 |
| CSS Cascade L5 | Candidate Recommendation Snapshot | 13.01.2022 |
| CSS Properties and Values API L1 | Working Draft | 26.03.2024 |

**Наблюдение (правило 4 и предупреждение заказа):** зрелость по статусу и зрелость по реализации РАСХОДЯТСЯ. `@layer` (Cascade 5) живёт в CR с 2022 года; `prefers-*` (MQ5) и `color-mix()`/`light-dark()` (Color 5) — в Working Draft, при этом реализованы широко. Ни одна из этих норм на дату сверки не Recommendation. Путать «повсеместно поддержано» и «стандарт» здесь особенно легко.

## Что осталось не закрытым — честно

1. **Метатег `color-scheme`** (вопрос 1) — взят через практику; прямой выписки HTML Standard нет.
2. **Анонимные слои и `@import … layer()`** (вопрос 3) — не выписаны дословно.
3. **Механика групп режим×бренд** (вопрос 5) — в доках Tokens Studio «coming soon».
4. Не выписаны вторые свидетели-практики из гипотез: MDN (light-dark, dark mode), Material 3 (модель схемы цветов), Radix Colors (тёмные варианты шкал), Open Props, Tailwind (форма записи тёмного режима). Часть — вторые свидетели уже закрытых ответов.
