# 🔘 Button

🏷️ actions · 🧬 component · 📐 compact · 📦 `@omnifield/probe-web-ui`

Обычная кликабельная кнопка — подпись, необязательная иконка, три вида (`primary`/`quiet`/
`danger`). Единственный компонент кита без составного дерева — один узел, ему нечего адресовать
внутри себя.

<h2 id="анатомия">🧩 Анатомия</h2>

Кнопка — один узел, не дерево из частей: класть внутрь можно что угодно (текст, иконку, и то, и
другое сразу), но адресовать по отдельности нечего — стилизуется только сама кнопка целиком.

```
root
```

| часть      | значение                                                         | принимает внутри | рисуется |
| ---------- | ------------------------------------------------------------------ | ------------------ | ---------- |
| 🔘 `root`  | кнопка целиком — один узел, по умолчанию настоящий `<button type="button">` | текст, иконку       | `Button`  |

<h2 id="состояния">🎛️ Состояния</h2>

Часть состояний — обычное поведение любой кнопки (навели, зажали, сфокусировали с клавиатуры,
отключили). Остальные два — `expanded` и `pressed` — сама кнопка никогда не выставляет, это
атрибуты про то, чем кнопка управляет СНАРУЖИ: раскрыла что-то или зажата как переключатель, — вид
кнопка берёт на себя, а сам факт кладёт тот, кто владеет этим поведением.

|      | состояние     | метка                | значение                                                                             |
| ---- | ------------- | ---------------------- | ---------------------------------------------------------------------------------------- |
| 🖱️   | hover         | `:hover`               | указатель наведён на кнопку                                                              |
| ⌨️   | focus-visible | `:focus-visible`       | фокус пришёл с клавиатуры                                                                |
| 👆   | active        | `:active`               | кнопка нажата и удерживается                                                             |
| 🚫   | disabled      | `[data-disabled]`       | нельзя нажать — обработчик не вызывается                                                 |
| ⏳   | busy          | `[aria-busy="true"]`    | идёт работа — атрибут ставит потребитель вместе с `disabled`, свой `loading`-проп кит не несёт |
| 📖   | expanded      | `[data-expanded]`       | кнопка раскрыла то, чем управляет — атрибут приходит от внешнего компонента              |
| 👇   | pressed       | `[data-pressed]`        | кнопка-переключатель нажата — сама нажатость принадлежит внешнему компоненту, вид — кнопке |

> [!NOTE]
> `expanded`/`pressed` кнопка никогда не ставит сама — это атрибуты, которые кладёт СНАРУЖИ тот,
> кто владеет поведением (свой `data-expanded="" `/`data-pressed=""` на самом узле `<Button>`, не
> через `as`-композицию с другим компонентом кита — см. предупреждение в «Использовании» и
> `FAQ.md`). Кнопка их только адресует в паспорте — сама логику раскрытия/нажатости не хранит.

<h2 id="io">🔌 IO</h2>

Собранной по схеме кнопке нужны подпись и, если нужно, какая-то полезная нагрузка на клик — кнопка
эту нагрузку никак не смотрит и не меняет, просто возвращает как есть тому, кто слушает клик.

<h3 id="io-вход">📥 Вход</h3>

```json
{
  "label": "string",
  "data-variant": "string",
  "payload": "любое"
}
```

<h3 id="io-выход">📤 Выход</h3>

```tsx
const onDispatch = (event: DispatchedEvent) => {
  // Клик по кнопке, возвращает payload как есть — кнопка его не решает и не трогает.
  // event.context.payload = { id: "row-1" }
};

<RenderTree tree={tree} registry={registry} data={data} dispatch={onDispatch} />;
```

> [!NOTE]
> Кнопка — единственный компонент кита с `passport.selfAssembly`: голая ссылка `{ node: "button" }`
> в чужой сборке разворачивает клик → `select` и подпись из данных сама, без своих `on`/`children`
> на узле ссылки.

<h2 id="сборки">🏗️ Сборки</h2>

Одна сборка — кнопка, у которой внутри только подпись из данных. Иконка, свой вид или что-то ещё
внутри — дело того, кто кнопку использует, показывать это в схеме отдельным примером незачем.

<h3 id="сборка-base">🧱 base</h3>

```
root
  🏷️ text: {label}
```

<h2 id="рецепт">🎨 Рецепт</h2>

Три именованных вида — `primary` (главное действие), `quiet` (второстепенное), `danger`
(разрушительное) — и то, как они выглядят, когда нажаты сразу оба сильных вида
(`primary`+`danger`), не просто по отдельности.

<h2 id="использование">🚀 Использование</h2>

Кнопку можно собрать вручную, отдать данные по схеме — своей или как готовую ссылку внутрь чужой
сборки, — переключить вид простым атрибутом или отрисовать вовсе другим тегом.

**Ручная сборка** — компонент собирается вручную, JSX-композицией, без схемы и движка.

```tsx
<Button onClick={save}>Save</Button>
```

**Как ссылка на чужую сборку** — через `selfAssembly` клик и подпись разворачиваются сами, без
собственных `on`/`children` на узле ссылки.

```tsx
const tree: AssemblyTree = {
  components: {
    root: "ref",
    nodes: {
      ref: { id: "ref", type: "button", parentId: "owner", children: [], bind: { label: "/title", payload: "/payload" } },
    },
  },
};

<RenderTree tree={tree} registry={registry} data={{ title: "Открыть", payload: { id: "s1" } }} />;
```

**Вид через `data-variant`, не проп.** У кнопки нет прописанного имени вида по умолчанию —
непереданный вид не ставит атрибут вовсе.

```tsx
<Button data-variant="primary">Save</Button>
```

**Рисуется другим тегом** — `as` меняет корневой элемент, адрес и вид кнопки остаются кнопкиными.

```tsx
<Button as="a" href="/orders">
  Открыть заказы
</Button>
```

> [!WARNING]
> `as` на ГОЛЫЙ тег (как выше) — рабочий, проверенный путь. `as` на ДРУГОЙ компонент кита,
> построенный поверх Ark (`Toggle`, `ToggleGroupItem` и т.п.) — известный предел, не рабочий путь:
> финальный узел получает адрес ЦЕЛИ (`data-scope="toggle"`), не кнопки, и скин кнопки просто
> перестаёт применяться. Подробности и почему — `FAQ.md`.
