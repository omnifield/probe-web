# 🔤 Typography

<h2 id="главное">🏠 Главное</h2>

🏷️ other · 🧬 component · 📐 regular · 📦 `@web-core/ui`

Текст с настроенным видом 🔤 — тег и внешний вид выбираются НЕЗАВИСИМО друг от друга: `<h2>` может
выглядеть как подпись, `<span>` — как заголовок. Ни Ark, ни Kobalte своего примитива для этого не
дают — этот компонент кит строит с нуля, тем же приёмом, что и `Surface`.

<h2 id="анатомия">🧩 Анатомия</h2>

Один узел, без внутреннего деления — стилизуется целиком, а не по частям.

```
root
```

| часть     | значение                                                        | принимает внутри       | рисуется      |
| --------- | ------------------------------------------------------------------ | ---------------------- | ------------------ |
| 🔤 `root` | текст — какой у него тег и какой вид, решаются раздельно            | текст, любой компонент | `Typography`    |

Своих состояний нет — текст ничего не хранит, чем его вид мог бы отличаться сам по себе.

<h2 id="использование">🚀 Использование</h2>

Собрать текст можно вручную или по схеме. 🧩

**Ручная сборка** — компонент собирается вручную, JSX-композицией, без схемы и движка. Тег выбирает
потребитель через `as`: заголовок остаётся семантическим `<h1>`, даже если визуально выглядит как
мелкая подпись, и наоборот.

```tsx
<Typography>Обычный текст — рисуется как <p></Typography>

<Typography as="h1" data-variant="heading">Заголовок страницы</Typography>

<Typography as="span" data-variant="caption">Мелкая подпись</Typography>
```

**Рендер через движок** — та же композиция, но по схеме (сборка `basic`), которую рисует
`RenderTree`.

```tsx
const tree = instanceOf("typography", {}, "basic", {});

<RenderTree tree={tree} registry={registry} data={{}} />;
```

<h2 id="сборки">🏗️ Сборки</h2>

<h3 id="сборка-basic">🧱 basic</h3>

Один узел с текстом.

```
root · text: "Текст"
```

<h2 id="рецепт">🎨 Рецепт</h2>

Одна часть, состояний нет — вместо них у текста три вариации: `body` (обычный текст, по умолчанию),
`heading` (крупный и жирный), `caption` (мелкий и приглушённый).

> [!NOTE]
> Как и у `Surface`, вариационная ось несёт ВЕСЬ вид компонента целиком — имена вариаций даёт
> человек в редакторе, кит их не хранит и не ограничивает. Тег (`as`) и вид (`data-variant`) —
> два независимых выбора: ничто не привязывает `<h1>` к варианту `heading`.
