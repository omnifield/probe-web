# Пульт — переключалка дев-серверов

**Одна вкладка вместо запоминания портов.** Слева зоны, справа то, что выбрано.

```
node tools/dev-nav/server.mjs
# → http://localhost:4100/__nav/
```

Наружу проброси **только 4100** — остальные порты пульт разбирает внутри.

## Почему прокси, а не список ссылок

Дев-серверы живут на разных портах, и каждый порт пришлось бы пробрасывать из контейнера
отдельно — ровно та возня, ради ухода от которой это написано.

Прямая ссылка на `localhost:5173` в рамке тоже не годится: снаружи этот порт недоступен,
а через префикс вроде `/z/tables/` ломаются абсолютные пути, которые отдаёт Vite
(`/@vite/client`, `/src/…`, `/node_modules/…`). Поэтому проксируется **всё**, кроме
собственных страниц пульта, и уходит на выбранную зону.

Горячая перезагрузка проксируется тоже — иначе правка в редакторе не доезжала бы до окна,
и пульт стал бы способом смотреть на устаревшую страницу.

## Как добавить зону

Строка в `CANDIDATES` (`server.mjs`): идентификатор, подпись, порт. Список — **кандидаты, а не
раскладка**: пульт показывает те, что реально отвечают, и гасит остальные. Зона, поднявшаяся
позже, появится сама в течение нескольких секунд.

Порт зоны задаётся в её `scripts.dev` (`vite --port 5174 --strictPort`). `--strictPort` важен:
без него Vite молча берёт соседний свободный порт, и пульт покажет зону мёртвой, хотя она
поднята.

## Границы

Это **оснастка локации, а не продукт**: живёт вне зон, никем не публикуется, в поставку не
входит. Задача у неё одна — чтобы не лазить по портам, пока нет постоянного решения.

Ноль зависимостей: голый Node. Тянуть пакеты ради одного прокси и одной страницы незачем.
