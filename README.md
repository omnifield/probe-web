# probe-web

Полигон **производства веба**. Проверяем не качество фреймворка, а то, что чужая команда может подняться на поставках baser и **отдать свой обвес**.

## Что проверяем

До сих пор мы проверяли только потребление наших собственных обвесов. Здесь — обратная сторона: локация делает обвес **сама** и публикует его, а собирает из него уже другой (`omnifield/sandbox`).

Цель — hello-world, а не хороший фреймворк. Достаточно, чтобы фронт поднялся.

## Что здесь стоит

Фундамент целиком с поставок, руками положено только объявление, настройки и этот файл:

| что | откуда |
|---|---|
| `.devcontainer/` | `@omnifield/baser-devbox`, канал `dev` |
| `.claude/` | `@omnifield/brainer-harness`, канал `latest` |
| `baser.lock.json` | паспорт укладки |

Проверить, что дерево не разъехалось:

```sh
baser plan     # → сошлось
```

## Как это ставилось

```sh
npm i -g @omnifield/baser-cli
baser add @omnifield/baser-devbox    --channel dev
baser add @omnifield/brainer-harness --channel latest
```

Пресет `omnifield` вписан в `.omnifield/omnifield-devbox.yaml` руками — **это временно**: аргумент `--preset` ещё не сделан (`tasker:BASER2-209`). Когда появится, ручной шаг исчезнет.

## Правила площадки

1. **Это полигон, а не продукт.** Сделали, посмотрели, снесли. Роадмапов тут не ведут.
2. **Корень держим пустым.** Всё, что в нём появляется, либо привезено обвесом и записано в паспорт, либо объяснено здесь.
3. **Раскладка зон в `harness.yaml` — догадка**, а не контракт: её ставил architect `baser` при заведении, менять её вправе architect этой локации.
