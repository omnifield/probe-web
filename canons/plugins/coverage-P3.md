# Карта покрытия — заказ P3 (isolation-and-permissions)

Собрано 2026-08-14.

| # | вопрос | чем закрыт |
|---|---|---|
| 1 | как изолируется расширение (процесс, песочница, общий рантайм) | `webextensions-content-scripts` (isolated world / Xray: общий DOM, раздельный JS-мир) · `vscode-workspace-trust` (граница по содержимому, не по расширению) · `osgi-core-8-security` (общий рантайм + права, не процессная песочница) |
| 2 | как заявляются права, кто подтверждает | `webextensions-permissions` (заявлены в манифесте, подтверждает пользователь на установке) · `osgi-core-8-security` (назначает деплойер через Permission Admin) |
| 3 | минимальная привилегия по умолчанию | **расхождение:** `gaps/default-privilege-empty-vs-full` (WebExtensions пусто · VS Code полное доверие · OSGi зависит) |
| 4 | доступ к внутренностям среды: публичное vs закрытое | `osgi-core-8-security` (аутентификация по location/signer, права по location) — **частично** |
| 5 | объявляется ли граница доверия явно | `vscode-workspace-trust` (явно: Trusted/Restricted) · `webextensions-permissions` (явно: заявленные права) · `osgi-core-8-security` (опционально) |
| 6 | доступ к ресурсам вне среды (сеть, ФС, буфер) | `webextensions-permissions` (host-права match-паттернами, отдельные API-права) |
| 7 | что при нарушении границы | **частично.** OSGi → `SecurityException` (детали в §51, не выписаны); WebExtensions/VS Code — не выписано |
| 8 | изолирован ли сбой расширения от среды | `vscode-extension-host` (Extension Host не даёт расширению влиять на старт, тормозить и менять UI) — **частично**: изоляция расширений друг от друга дословно не сказана |

## Что осталось открытым

- **Вопросы 7 и 8** — не закрыты выпиской. Кандидаты на добор: VS Code «Extension Host» (процессная изоляция, отказоустойчивость), OSGi §51 Permission Admin (поведение при отказе в праве), MDN content scripts (изоляция исполнения в отдельном мире).
- **Процессная модель** (Q1) названа, но не выписана дословно ни для одной среды.

## Норма органа против практики проекта

- **Норма органа:** OSGi Core R8 §2 Security Layer (но слой опционален).
- **Практика проекта:** WebExtensions (Mozilla/MDN), VS Code Workspace Trust (Microsoft).
- **Главный вывод:** «минимальная привилегия по умолчанию» — не общерыночная норма, а норма сред с недоверенным источником расширения (см. расхождение).
