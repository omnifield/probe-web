# 📊 Diagram

🏷️ other · 🧬 component · 📐 wide · 📦 `@omnifield/probe-web-ui`

Второй по-настоящему СВОЙ составной компонент кита (после `table`) — Ark UI диаграмм не даёт вовсе,
ни готовых, ни headless. Вся анатомия объявлена нами; движок под расчётами (шкалы, пути, отсечения)
— предмет отдельного решения, не выбран пока (см. `FAQ.md`).

> [!NOTE]
> Скелет. Анатомия сейчас — ровно `root`, голый `<svg>` без семьи графиков (декартовы/радиальные/…)
> и без движка расчётов внутри. Реальная форма компонента (что берём из `products/diagrams`
> референса, что строим заново) — предмет ближайшего обсуждения, не решена в этом коммите.

> [!TIP]
> Перед тем как начинать реализацию — прочитай [`FAQ.md`](./FAQ.md): туда пойдут конкретные
> грабли этого компонента, тем же способом, каким `table/FAQ.md` собрал грабли
> `@tanstack/solid-table`.
