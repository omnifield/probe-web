# Карта покрытия — заказ J (visual-proof)

**Сбор от 2026-08-15.** Чем доказывают, что вид не сломался, и — важнее — чего проба принципиально не может. По каждому из 8 вопросов: чем закрыт и что осталось.

Собрано: 3 новые выписки (playwright-screenshots, axe-core, stylelint-declaration-strict-value); 3 записи пробелов. Заход по замыслу даёт много ПРОБЕЛОВ — это и есть его результат (вокруг непокрытого строятся ложные ожидания).

## Находки (прямо по замыслу заказа)

- **Снимок изображения слеп к ПРИЧИНЕ**: `toHaveScreenshot` говорит, что пиксели отличаются, но не почему (разметка/тема/значение мимо шкалы). Разные пробы ловят разное, и снимок — не универсальный.
- **Знаменитый ПРОЦЕНТ авто-детектируемого a11y — не из первичной доки средства**: в API axe-core его нет. Ровно «цифра без источника», о которой предупреждал заказ.
- **Три «тихих» поломки оформления (тема не переключилась, зацепка отвалилась, forced-colors сломал вид) — без объявленной пробы-стандарта**: механизмы есть, средства именно под эти вопросы рынок не декларирует.

## Проверка гипотез (правило 5)

- Гипотеза «средства объявляют долю авто-детектируемого» — НЕ подтвердилась в первичных доках (`gaps/a11y-auto-detectable-proportion.md`).
- Гипотеза «есть проба на все темы / работу без стилей / forced-colors+zoom» — в основном НЕ подтвердилась (`gaps/hard-visual-proofs.md`).

## Что осталось не закрытым — честно

1. **Вопросы 5, 6, 7, 8** — четыре пробела; это ожидаемый и ценный результат захода.
2. **Доборы**: DOM-snapshot и проверка вычисленных стилей (Testing Library/jsdom, Q1); границы правила контраста axe (Q3).
3. Не выписаны из гипотез (в т.ч. с проверкой статуса — часть могла быть остановлена/сменить владельца): Chromatic, Storybook test-runner, BackstopJS, Percy, Loki; Lighthouse, Pa11y, IBM Equal Access; Testing Library, jsdom. Chromatic/Storybook modes — кандидат частично закрыть Q6.
