# ❓ FAQ

Короткие ответы на конкретные вопросы, которые уже возникали по этому компоненту. Не общая
документация (она в [`README.md`](./README.md)) и не план (он в [`ROADMAP.yaml`](./ROADMAP.yaml))
— только факты, каждый проверен на практике.

---

### Почему анатомия карусели взята из `@ark-ui/solid/anatomy`, а не напрямую из `@zag-js/carousel/anatomy`, как у большинства компонентов кита?

**Коротко: «сырая» анатомия из Zag короче на два узла, которых кит реально использует — `progressText` и `autoplayIndicator`.**

`@zag-js/carousel/anatomy` описывает десять частей — движок, который решает, какой слайд сейчас
виден, и ничего не знает про удобства сверху. Слой Ark добавляет `progressText` (счётчик страниц)
и `autoplayIndicator` (собственная иконка кнопки автопрокрутки) поверх этого набора — оба реально
адресуются в паспорте кита. Взять «сырую» версию из Zag означало бы молча потерять два узла,
которые компоненты кита на самом деле рисуют.

### Почему клик по стрелке/точке не проверен тестом, хотя это самая базовая функция карусели?

**Коротко: настоящая страница определяется через `IntersectionObserver` после настоящей прокрутки — jsdom не выполняет ни то, ни другое.**

В браузере переход между страницами карусели — это не мгновенная смена состояния по клику, а
следствие: клик запускает `scrollTo`, а какая страница «текущая» решает браузер, реально сообщая
через `IntersectionObserver`, какой слайд видно на экране. В тестовом окружении оба механизма —
заглушки без единого настоящего события, поэтому клик по стрелке или точке не меняет ничего
наблюдаемого. Это ограничение среды, не дефект компонента — подробности и честная пометка каждой
такой фичи как непроверенной — `ROADMAP.yaml`.

### Почему `progressText` в базовой сборке ничего не показывает, и как вообще получить текст вида «2 из 5»?

**Коротко: узел смонтирован, но без переданного содержимого показывать ему нечего — а способ получить готовый текст (`api().getProgressText()`) кит сейчас не пробрасывает вовсе.**

`CarouselProgressText` — обычная часть с адресом, куда нужно положить готовый текст самому; сам
узел число страниц не форматирует. Компонент-первоисточник умеет это отдать в одну строку —
`getProgressText()` на объекте API, доступном через `CarouselContext`/`useCarouselContext` — но
кит их не реэкспортирует ни из одного файла: ни `CarouselContext`, ни `useCarouselContext`, ни
`useCarousel` не входят в `components/index.ts`. Собрать живой прогресс-текст (и вообще что угодно
из объекта API — `scrollToIndex`, `play`/`pause`, `isPlaying`) сейчас можно только импортируя это
напрямую из `@ark-ui/solid/carousel`, в обход кита. Честно вынесено как пробел — `ROADMAP.yaml`.
