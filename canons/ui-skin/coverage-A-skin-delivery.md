## Что осталось не закрытым — честно

Каждый из 8 вопросов закрыт выпиской либо записью в `gaps/`. Не закрытым по сути осталось следующее:

1. **Вопрос 8** — пробел (контракт стороннего скина): есть поверхность зацепок, нет версионированного контракта. `gaps/skin-contract-for-third-party.md`.
2. **Вопрос 5 (цифры)** — пробел по измеренным величинам; механизм закрыт тремя выписками. `gaps/measured-skin-weight.md`.
3. **Вопрос 2** — «работоспособен без СВОЕГО вида» прямо заявлено только для headless-наборов (там вида нет вовсе); для стилизованных наборов такого утверждения не найдено.
4. **Вопрос 7** — совместимость закрыта диапазоном peer-зависимости; поведение вида при мажоре набора (уровень CHANGELOG) не разобрано.
5. Не выписаны из гипотез: Headless UI, Ark UI/Park UI, Kobalte, corvu, Melt UI, Zag.js, Vanilla Extract, Stitches (проверить статус — мог быть остановлен), CVA, Spectrum CSS, Material Web, Carbon, USWDS, Bootstrap, Catalyst.
