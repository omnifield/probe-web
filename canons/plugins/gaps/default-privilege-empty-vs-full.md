# Расхождение: набор прав расширения по умолчанию — пустой или полный?

**Вопрос (заказ P3, вопрос 3):** с каким набором прав расширение стартует, если ничего не объявило?

Источники отвечают **противоположно** — и это не дефект какого-то из них, а разные модели доверия. Приводятся все; выбор не делается.

## Ответ A — пустой набор, минимальная привилегия (WebExtensions)

Ключ `permissions` не обязателен; без него у расширения нет «особых сил». Каждое право заявляется явно и подтверждается пользователем на установке.

> Use the `permissions` key to request special powers for your extension.
> — `sources/webextensions-permissions.md`

Модель: расширение недоверенно по умолчанию, права добираются явно.

## Ответ B — полное доверие по умолчанию (VS Code)

Установленное расширение включено и доверено; граница доверия проведена по содержимому папки, а не по расширению.

> By default, if you open a new VS Code window (instance) without opening a folder or workspace, VS Code runs the window with full trust. All installed extensions are enabled and you can use the empty window without restrictions.
> — `sources/vscode-workspace-trust.md`

Модель: расширение доверенно по умолчанию, per-extension набора прав нет.

## Ответ C — зависит от того, включена ли безопасность (OSGi)

Слой безопасности опционален. При включённом — тонкогранульные права (Permission Admin). При выключённом/заглушках — эффективно полный доступ.

> This behavior allows code to run as if all bundles have AllPermission.
> — `sources/osgi-core-8-security.md`

## Почему оставлено расхождением

Разница коренится в том, откуда приходит расширение и кто несёт риск. Браузер ставит недоверенный код из веба и потому по умолчанию не даёт ничего. Редактор ставит расширение, которое пользователь выбрал сам из магазина, и потому доверяет ему как своему коду, перенося недоверие на **открываемое содержимое**. Модульная платформа (OSGi) отдаёт решение деплойеру. Это три разные политики для трёх разных моделей поставки, а не три мнения об одном. Выбор — решение владельца среды.

## Общий вывод для рамки

**«Минимальная привилегия по умолчанию» НЕ является рыночной нормой для расширяемых сред в целом.** Она норма там, где источник расширения недоверенный (браузеры). Там, где расширение выбирается пользователем осознанно (редакторы), рынок склоняется к полному доверию расширению и переносу забора на данные. Опереться на единое «по умолчанию пусто» нельзя — этого консенсуса нет.
