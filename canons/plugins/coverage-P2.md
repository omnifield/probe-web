# Карта покрытия — заказ P2 (lifecycle-and-versioning)

Собрано 2026-08-14.

| # | вопрос | чем закрыт |
|---|---|---|
| 1 | обязательные стадии жизни, кто инициирует | `osgi-core-8` (INSTALLED→RESOLVED→STARTING→ACTIVE→STOPPING→UNINSTALLED; API обязан покрыть install/start/stop/update/uninstall) |
| 2 | точки входа в стадии, падение на старте | `osgi-core-8` (Bundle Activator start/stop; Bundle Context) — **частично**: обработка исключения в start дословно не выписана |
| 3 | зависимости, гарантия порядка, цикл/неудовлетворённость | `osgi-core-8` (RESOLVED = все зависимости удовлетворены; старт после ACTIVE фреймворка) — **частично**: поведение при цикле не выписано |
| 4 | форма объявления версии среды, семантика диапазона | `npm-package-json-engines` (semver-диапазон, `*`=любая) · `vscode-extension-manifest` (`engines.vscode`, `*` запрещён) · `semver-2.0.0` (смысл приращений) · `node-semver-ranges` (грамматика `^`/`~`/x-диапазонов) |
| 5 | что среда делает с несовместимым | **расхождение:** `gaps/version-mismatch-advisory-vs-enforced` (npm — advisory; VS Code — обязателен, `*` нельзя) |
| 6 | эволюция контракта, ломающее, deprecation | `semver-2.0.0` (MAJOR = несовместимое; MINOR обязателен при deprecation) |
| 7 | неизвестное поле в манифесте | **не закрыто.** VS Code перечисляет известные поля, но молчит о поведении при поле вне списка; кандидат в gap/добор (WebExtensions: браузеры игнорируют неизвестные ключи — не выписано дословно) |
| 8 | горячие установка/обновление/снятие | **не закрыто.** OSGi имеет `update`, но гарантии активным потребителям снимаемого бандла дословно не выписаны |

## Что осталось открытым

- **Вопросы 7 и 8** — не закрыты выпиской. Кандидаты: node-semver (грамматика диапазонов для добора Q4), OSGi Module Layer §3 (Import-Package version ranges, поведение при неразрешённой зависимости — Q3/Q7), WebExtensions (неизвестные ключи — Q7).
- Обработка падения расширения в момент старта (Q2) и цикла зависимостей (Q3) — есть в OSGi, но требуют выписки из §4.4–§4.5, не сделанной в этот заход.

## Норма органа против практики проекта

- **Норма органа:** OSGi Core R8.
- **Де-факто стандарт:** SemVer 2.0.0.
- **Практика проекта:** npm (npm, Inc.), VS Code (Microsoft).
