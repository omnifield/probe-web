# generators

Код-генерация этого кита — один генератор на подпапку, каждый производит своё из одних и тех же
папок компонентов (`src/*`).

Сам механизм обхода/сбора данных/рендера/записи не отсюда — он в `@probe-web/generators`
(отдельный продукт репозитория, `products/generators`). Здесь — только то, что знает про раскладку
ИМЕННО этого кита: где у компонента паспорт, что значит "часть", какой текст должен получиться.

## Что здесь есть

| папка | что производит | команда |
|---|---|---|
| [`barrel/`](barrel/README.md) | агрегирующие входы кита — один файл на ВСЕ компоненты сразу (`passport.ts`, `kit.ts`, `io.ts`, `index.ts`) | `pnpm run generate` |
| [`readme/`](readme/README.md) | МЕХАНИЧЕСКАЯ часть документации — таблицы anatomy/states/settings, один `README.md` на КАЖДЫЙ компонент | `pnpm run readme` |
| [`prompt/`](prompt/README.md) | ПРОЗА для документации — не пишет её сама: собирает промпт (`out/<имя>.md`) с паспортом+editorInfo+реальным исходником компонента, промпт затем читает и исполняет отдельный агент, результат кладёт в `README.md`'s `## Notes` | `pnpm run prompt` |

**Полное README компонента — это `readme/` (таблицы) + агент, отработавший по `prompt/`'s выводу
(проза в `## Notes`), не одно из двух.** Прогон одного `readme/` даёт файл с пустыми/`TODO`
таблицами и без прозы — это НЕ готовая документация, а только её механический каркас.

## Общее для всех генераторов здесь

**Компонент — это папка `src/*`, объявившая `entity/passport.ts`.** Ни один генератор не ведёт
отдельный список компонентов руками — компонент, у которого нет `entity/passport.ts`, для любого
генератора этой папки просто не существует.

**Шаблоны — Handlebars-файлы (`*.hbs`), не JS-функции.** Каждая подпапка несёт свои `templates/*`
рядом со своим скриптом — сам текст того, что генератор производит, живёт там, а не внутри логики
сбора данных.

**Каждый генератор — свой Nx-таргет** (`package.json`, `nx.targets`), не часть сборки: порождённое
нужно раньше сборки (или не нужно ей вовсе, как `readme`), и гонять сборку ради генерации значило
бы платить лишним проходом esbuild за каждую мелочь.
