# 🧷 Shared

Код и конфиг зоны `build`, нужный больше чем одной теме — заведён один раз, а не копией на
каждую тему, у которой похожая нужда.

- `trace.ts` — perf-логгеры (`vite/`, `vitest/`). Внутреннее, в `exports` не объявлено.
- `tsconfig.json` — строгие проверки компилятора, общие для `tsconfig/` (фронтенд) и `node/`
  (сервер): `strict`, `noUnusedLocals`, `verbatimModuleSyntax` и т.д. Расходится у профилей
  только то, что зависит от среды исполнения (DOM/JSX против `node`) — это остаётся в каждом
  профиле отдельно.
