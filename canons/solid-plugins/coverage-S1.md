# Карта покрытия — заказ S1 (extensibility-in-solid)

Собрано 2026-08-14. Всё — предписания/примитивы самого Solid (издатель solidjs) либо пробелы.

| # | вопрос | чем закрыт |
|---|---|---|
| 1 | вклад в UI динамическим компонентом | `solid-dynamic` (`<Dynamic component>`, реестр `views`, пропсы прокидываются, `undefined`→пусто) |
| 2 | контракт host↔расширение через контекст | `solid-createcontext` (Provider/useContext, `defaultValue` при отсутствии провайдера, тип `T\|undefined`) |
| 3 | реестр вкладов через реактивность | `solid-createstore` (proxy, трекинг на уровне свойства, path-обновления, `undefined` удаляет) · `solid-produce-reconcile` (глубокая мутация / сведение внешнего снимка по `id`) |
| 4 | владение и жизненный цикл вне дерева | `solid-runwithowner` (getOwner+runWithOwner восстанавливают очистку/контекст; ловушка после `await`) |
| 5 | ленивая загрузка расширения | `solid-lazy` (dynamic import по требованию, `preload()`, `<Suspense>` fallback) |
| 6 | изоляция и отказоустойчивость | `solid-errorboundary` (ловит рендер/обновление поддерева + `reset`; НЕ ловит из обработчиков событий) |
| 7 | расширение отдельным пакетом, две копии solid-js | `gaps/two-copies-of-solid-js` (предписание peer+`solid`-export первично; «почему» в доке не нормировано) |
| 8 | официальный паттерн «плагин» | `gaps/no-official-plugin-pattern` (паттерна нет; Solid даёт примитивы, не модель) |

## Что осталось открытым (в пределах закрытых вопросов)

- Q6: изоляция сбоя частична — ошибки обработчиков событий забор не ловит (названо прямо); полной песочницы у Solid нет.
- Q7: дословная формулировка ядра о причине двух копий — не найдена (честный пробел).

## Что предписано документом/линтером, а что практика

- **Предписание Solid (первичный, издатель solidjs):** все шесть примитивов из `sources/` — документация организации solidjs.
- **Практика/конвенция без нормы-объяснения:** публикация расширения-пакета (peer + `solid` export condition) — конвенция инструментов solidjs, но механизм «почему» в основной доке не поднят.
- **Отсутствие нормы:** плагинной архитектуры как паттерна Solid не предписывает вовсе.
