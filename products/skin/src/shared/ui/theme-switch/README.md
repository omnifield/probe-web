# Theme switch

Подключение скина продукта, выбор наряда по имени и переключатель половины (светлая/тёмная) — в
одном компоненте. Поверх `createSkinConnection` (`@web-core/runtime`, PWEB-213), на
компонентах кита — `Select` для выбора скина, `Toggle` для половины.

## Зачем одним компонентом

Подключение скина само по себе не нужно ни для чего, кроме как дать переключателям что
переключать — разносить их по разным местам значило бы городить связь между файлами вместо
одного самодостаточного.

## Скин — по `Select`, половина — по `Toggle`

Наряд и половина — разные оси (наряд — ЧТО надето, половина — светлая или тёмная ПАРА того же
наряда), поэтому и управление разное: `Select` — выбор одного значения из списка (имена нарядов
из `SOURCE.names()`), `Toggle` — бинарный переключатель (`pressed` = тёмная).

## Зачем `createSkinConnection`, а не `makeSkinSwitch`

`SkinSwitch.worn()` (низкоуровневая механика, `packages/runtime`) — обычная функция, читает
атрибут с корня по запросу и сама за собой не следит. `createSkinConnection` — то же самое, но
`worn` уже сигнал: обновляется сам после `wear`/`takeOff`/`restore`, ничего досинхронизировать
руками не нужно (в старом коде эта досинхронизация писалась руками дважды подряд на этом же
продукте — заявка ушла в движок, `PWEB-213`, оттуда и переехало).

## Один скин, не список

Раньше наряд выбирали из перечня, который отдавала служба пресетов. Сегодня выбирать не из
чего — один локальный `SKIN` прямо в файле (тем же приёмом, что `apps/reference/src/skin.ts`), и
`SOURCE` просто называет его единственным именем.

## `SKIN.recipes` — пустой

Подключение реальное — лист стилей заведён, `data-skin` стоит на корне, половина запоминается
между заходами. Красить пока нечем: рецепты компонентов заводятся по одному вслед за китом,
отдельной задачей (`skin-from-shipped-recipe` — от эталона поставки, не с нуля).

## Использование

```tsx
import { ThemeSwitch } from "#/shared/ui/theme-switch/index.jsx";

<ThemeSwitch />
```

Ставится один раз в постоянном каркасе (не на отдельной странице) — скин один на всё приложение,
второй экземпляр завёл бы второй лист стилей на тот же документ.
