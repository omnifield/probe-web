# Ландшафт Solid-обёрток движков карт и их живость (снимок 2026-08-14)

**Вопрос (заказ M1, вопрос 1):** какие Solid-обёртки движков карт существуют и живы?

Обёрток несколько, все — практика сообщества (не орган), с РАЗНОЙ живостью. Статусы ниже — снимок на 2026-08-14; часть данных по дате публикации взята с npm (**вторичный** признак живости, не первичный текст).

## Что найдено

| обёртка | движок | версия | последняя публикация | сверка |
|---|---|---|---|---|
| `solid-map-gl` (GIShub4) | Mapbox GL / MapLibre | 1.13.0 | ~8 мес назад (≈конец 2025) `[вторичный: npm]` | package.json первично — `sources/solid-map-gl.md` |
| `solid-maplibre` (shishkin) | MapLibre GL JS | 0.5.0 | ~3 мес назад (≈май 2026) `[вторичный: npm]` | package.json не выписан |
| `solid-maplibre` (birkskyum) | Mapbox GL | — | не сверено | одноимённый репозиторий, требует различения от shishkin |

## Что это значит для выбора

- **`solid-map-gl`** — самая полнофункциональная (3D-стек babylon/three в peer), но публикация реже и peer-диапазоны открыты настежь (`"*"`), см. `sources/solid-map-gl.md`.
- **`solid-maplibre` (shishkin)** — публикуется свежее, уже 0.x (нестабильный мажор по SemVer — API может ломаться), только MapLibre.
- Два разных пакета с именем `solid-maplibre` (shishkin и birkskyum) — при выборе легко перепутать; различать по автору репозитория.

## Почему это пока запись в gaps, а не выписки

Первично (по `package.json`) выписан только `solid-map-gl`. Живость альтернатив установлена по дате публикации npm — это **вторичный** признак: он говорит «давно ли релиз», но не о совместимости с текущим Solid 1.9.x и MapLibre. Чтобы поднять `solid-maplibre` до выписки, нужно свести его `package.json` (версия Solid в peer, `solid` export condition, поддерживаемая версия MapLibre) — не сделано в этот заход.

## Не закрыто (добор)

- `package.json` shishkin/solid-maplibre — первичная сверка peer `solid-js`/`maplibre-gl`, `solid` export condition.
- Различить birkskyum/solid-maplibre и shishkin/solid-maplibre: форк, преемник или независимые.
- Обёртки OpenLayers/Leaflet для Solid — существуют ли живые.
